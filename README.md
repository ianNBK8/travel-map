# 旅程地圖

一個單檔網頁 App（`index.html`），把行程排在地圖上。不需要安裝、不需要 API key，資料存在瀏覽器裡。

## 功能

| 功能 | 怎麼用 |
|---|---|
| 自動定位 | 開啟時自動定位（需允許位置權限），右上「我的位置」可重新定位 |
| 連結 Google Maps | 每個活動都有「Google 地圖」「導航」；每天有「整天路線」（大眾運輸模式，最多 9 個中途點）；兩站之間有「查交通方式」 |
| 一鍵搜尋 | 地圖上方搜尋框找地點，按「加入」直接進行程；下方標籤（餐廳、咖啡廳、便利商店…）一鍵在 Google 地圖搜尋附近 |
| 點地圖加入 | 點地圖任一處，會顯示地址並可加入當天行程 |
| 顯示圖片 | 自動從 Wikipedia 找景點照片；點縮圖可上傳自己的照片、貼圖片網址或用 Google 圖片搜尋 |
| 拖曳排序 | 抓住卡片左側的 ⋮⋮ 拖曳；也可按「依時間排序」 |
| 改時間 | 直接點卡片上的時間修改 |
| 新增活動 | 「＋ 新增活動」可設定名稱、日期、時間、地點（搜尋／地圖點選／目前位置）、備註 |
| 備註 | 卡片上直接打字，自動儲存 |
| 多天行程 | 上方 DAY 分頁，「＋」新增一天；編輯活動時可移到其他天 |
| 匯出 Excel | 右上「匯出 Excel」，含日期、時間、地址、備註、可點擊的 Google 地圖／導航連結 |
| 備份 | 「⋯」選單可匯出／匯入 JSON 備份（換手機或換瀏覽器時用） |

## 開啟

手機或電腦直接開：**https://iannbk8.github.io/travel-map/**

手機可用瀏覽器的「加入主畫面」，像 App 一樣使用。第一次開啟請允許位置權限。

## 資料與限制

- 行程存在瀏覽器的 localStorage：換瀏覽器或清除網站資料會不見，重要行程請用「備份」匯出 JSON。
- 上傳的照片會壓縮到 800px 存在瀏覽器，數量太多可能塞滿空間（約 5MB），建議多用圖片網址。
- 地圖與搜尋使用 OpenStreetMap（Nominatim），搜尋請勿連續狂按（每秒 1 次限制）。
- 圖片來自 Wikipedia，冷門地點可能找不到，可以手動補。

## 使用的開源套件

Leaflet 1.9.4（地圖）、SortableJS 1.15.2（拖曳）、SheetJS 0.18.5（Excel）、OpenStreetMap 圖資。
